# Сборка игры

Для разработки запустите `npm install`, затем `npm run dev`. Локальный сервер использует исходные PNG из `public`.

Для производственной сборки установите Python и Pillow с поддержкой WebP:

```sh
python -m pip install -r scripts/requirements-build.txt
npm run build
```

Результат находится в `dist`. Скрипт копирует только файлы из `scripts/runtime-assets.json` и преобразует PNG в WebP без потерь, сохраняя размеры кадров и прозрачность. При добавлении игрового ассета внесите исходный путь в этот список; отсутствие файла останавливает сборку. Оригиналы в `public` не изменяются. GitHub Actions устанавливает Pillow и выполняет ту же сборку перед публикацией Pages.

Титульный экран загружается первым; основные боевые ресурсы догружаются в меню. Музыка и фоны последующих локаций запрашиваются по мере необходимости.
